# OneDep Deposition API Wrapper (Deprecated)

This project has been deprecated and replaced by [onedep_lib](https://wwpdb.github.io/onedep_lib/), a Python library to interact with OneDep's APIs. For more information, check its PyPi package in https://pypi.org/project/onedep-lib/ and its GitHub page in https://github.com/wwPDB/onedep_lib.
